# ระบบพิมพ์ซองจดหมาย + ระบบพิมพ์เช็ค

> เว็บแอปเดียว มี 2 ระบบ: **ระบบพิมพ์ซองจดหมาย** และ **ระบบพิมพ์เช็ค** — ผู้ดูแลกำหนดสิทธิ์ให้ผู้ใช้แต่ละคนได้ว่าใช้ระบบไหน (ระบบเดียวหรือทั้งคู่)

## ระบบพิมพ์เช็ค (Cheque Printing System)

- **ธนาคาร:** กรุงไทย และ กสิกรไทย (เพิ่มธนาคารอื่นได้ที่เมนู "บัญชีเงินและธนาคาร") · ขนาดเช็ค **3.5" × 9.5"**
- **AC / Non-AC:** เลือกได้ทุกครั้งตอนออกเช็คและตอนพิมพ์ — แบบ AC พิมพ์ขีดคร่อม "A/C PAYEE ONLY" และเส้นขีดฆ่า "หรือผู้ถือ" ส่วน Non-AC ไม่พิมพ์ (ตั้งได้ในแบบฟอร์มว่ารายการไหนแสดงเมื่อใด)
- **ออกเช็ค:** บัญชี, ธนาคาร, เล่มที่, เลขที่เช็ค (เสนอเลขถัดไปให้), วันที่ (พิมพ์เป็น พ.ศ.), จ่าย (มีรายชื่อเดิมให้เลือก), จำนวนเงิน + **แปลงเป็นตัวอักษรภาษาไทยอัตโนมัติ** (เช่น 12,500.50 → หนึ่งหมื่นสองพันห้าร้อยบาทห้าสิบสตางค์), รายการ, ข้อมูลเงินงบประมาณ (บัญชีงบประมาณ)
- **ทะเบียนเช็ค:** ค้นหา/กรอง, ติ๊กเลือกหลายฉบับแล้วพิมพ์, แก้ไข, ยกเลิก (ระบุเหตุผล), ออกเช็คใหม่จากข้อมูลเดิม, เตือนเลขที่เช็คซ้ำ
- **พิมพ์:** หน้าตัวอย่างขนาดจริง 100% → เลือกแบบฟอร์ม + AC/Non-AC → พิมพ์ด้วยเอกสารขนาดเช็คจริง ขอบ 0 ไม่มีหัว/ท้ายกระดาษ (ไม่ใช่ PDF ของเบราว์เซอร์) · รองรับป้อนเช็คแนวนอน/แนวตั้ง (หมุน 90°) · พิมพ์ตรงไม่ผ่านหน้าต่างพิมพ์ได้ด้วย `--kiosk-printing`
- **แบบฟอร์มเช็ค (ของแต่ละผู้ใช้):** ทุกจุดบนเช็คแยกเป็นรายการ — วันที่ (ช่อง วว ดด ปปปป / ตัวอักษร), จ่าย, จำนวนเงินตัวอักษร/ตัวเลข (ใส่ ** หรือ = หน้า-หลังได้), ขีดคร่อม AC, ขีดฆ่าหรือผู้ถือ, รายการ, เลขที่เช็ค, ต้นขั้ว, ข้อความเพิ่มเอง — **ลากย้าย / กดลูกศร / ปรับ มม. / ซ่อน (ลบ)** ได้ทุกรายการ · **อัปโหลดภาพสแกนเช็คเปล่า** เป็นพื้นหลังเพื่อวางตำแหน่งให้ตรงช่องจริง (ไม่ถูกพิมพ์) · ตั้งชื่อแบบฟอร์ม, มีได้หลายแบบ, ตั้งแบบเริ่มต้นของแต่ละธนาคาร
- **คัดลอกแบบฟอร์มของผู้ใช้อื่น:** ต้องกด**ยืนยันการคัดลอก**ก่อน → ได้สำเนาเป็นของตัวเองโดยสมบูรณ์ — **ผู้สร้างต้นฉบับลบหรือแก้แบบของเขา ก็ไม่กระทบสำเนา**
- **แบบมาตรฐานตามเช็คจริง (ค่าเริ่มต้น):** วัดตำแหน่งจากเช็คเปล่าจริงของ**ธนาคารกรุงไทย**และ**ธนาคารกสิกรไทย**ทั้งแผ่น 9.5" × 3.5" (รวมต้นขั้วด้านซ้ายก่อนฉีก) — วันที่พิมพ์ลง**ช่อง 8 ช่อง** (ว ว ด ด ป ป ป ป), ชื่อผู้รับอยู่บนเส้น "จ่าย/Pay" พร้อมเส้นประปิดท้าย, \*\*จำนวนเงินตัวอักษร\*\* บนเส้น "จำนวนเงิน/บาท", \*\*ตัวเลข\*\* ในกรอบ ฿, ขีดฆ่า "หรือผู้ถือ", ตรา A/C PAYEE ONLY, ต้นขั้ว: วันที่/จ่าย/บาท บนเส้น และรายการบนเส้นหมายเหตุ (กสิกรไทย) · **ผู้ใช้ที่เข้าระบบเช็คครั้งแรกจะได้แบบฟอร์มมาตรฐานทั้ง 4 แบบอัตโนมัติ** (บันทึกในตาราง `cheque_forms`) และกด **⭐ สร้างแบบมาตรฐานตามเช็คจริง** ในหน้า "ตั้งค่าแบบฟอร์มเช็ค" เพื่อสร้างแบบที่ขาดได้
- **ตั้งค่าแบบฟอร์มเช็คแบบละเอียด:**
  - **แยกชิ้นส่วน** — กด ✂ ที่ "วันที่" (หรือ "ต้นขั้ว: วันที่") เพื่อแยกเป็น **วัน / เดือน / ปี** แล้วลากวางแต่ละชิ้นได้อิสระ (กด "⤺ รวมวันที่กลับ" เพื่อกลับเป็นชุดเดิม) และเพิ่มชิ้นข้อมูลอื่นได้ เช่น เฉพาะบาท / เฉพาะสตางค์, เดือนชื่อเต็ม/ย่อ, ปี 2 หลัก, เลขที่เช็ค, ชื่อบัญชี
  - **ปรับขนาดกล่องข้อความด้วยเมาส์** — จุดขวา = ยืด/หดความกว้าง (ยืดออก ขนาดอักษรเท่าเดิม · หดจนชนข้อความ ตัวอักษรเล็กลงอัตโนมัติ) · จุดล่าง/มุมขวาล่าง = ขยาย/ย่อขนาดอักษรตามกล่อง · หรือพิมพ์ขนาด (pt) เอง
  - **แบบอักษรเลือกได้ทีละรายการ** — TH SarabunPSK (ค่าเริ่มต้น), TH Sarabun, TH SarabunIT๙, ตัวหนา/ตัวเอียง และ**บาร์โค้ด Code 39 / Code 128** (ระบบเข้ารหัส start/stop/checksum ให้อัตโนมัติ เช่น บาร์โค้ดเลขที่เช็ค)
  - **+ เพิ่มข้อความ** — ระบบถามว่าข้อความนี้ต้อง**เพิ่มเป็นช่องกรอกในฟอร์มออกเช็ค**ด้วยหรือไม่: (1) ข้อความคงที่ (2) ข้อมูลที่มีอยู่แล้วในระบบ (3) **ช่องกรอกใหม่** — ตั้งชื่อช่อง ชนิด (ข้อความ/ตัวเลข/จำนวนเงิน/วันที่) ค่าเริ่มต้น และบังคับกรอกได้ → ช่องนี้จะปรากฏในหน้า "ออกเช็คใหม่" ของธนาคารนั้นทันที ค่าที่กรอกเก็บกับเช็ค (`cheques.extra`) และพิมพ์ตรงตำแหน่งที่วางไว้
  - **คัดลอกแบบของผู้ใช้อื่น** มาเป็นแบบของตัวเอง (ยืนยันก่อนคัดลอก) แก้ไขได้อิสระ — รวมช่องกรอกเพิ่มเติม แบบอักษร และชิ้นส่วนที่แยกไว้
- **ภาพเช็คด้านหลัง (ไม่ถูกพิมพ์):** หน้าตั้งค่าแบบฟอร์มและหน้าตัวอย่างก่อนพิมพ์แสดงภาพเช็คจริงของธนาคารนั้นไว้ด้านหลัง เพื่อจัดตำแหน่งให้ตรงเส้น/ช่อง (ปิดได้ด้วยช่อง "แสดงภาพเช็ค") · **เปลี่ยนรูปได้ 2 ระดับ:** ผู้ใช้กด "📷 เปลี่ยนรูป" เฉพาะแบบฟอร์มของตัวเอง หรือผู้ดูแลระบบเปลี่ยนภาพมาตรฐานของธนาคารที่เมนู **บัญชีเงินและธนาคาร → ภาพเช็คเปล่าของแต่ละธนาคาร** (สแกนเช็คทั้งแผ่น ครอปชิดขอบกระดาษ ระบบยืดให้เต็ม 241.3 × 88.9 มม.) ภาพที่มากับระบบอยู่ที่ `assets/cheques/ktb.jpg`, `kbank.jpg`
- **แบบตามรายงานเดิม (Access) — ยังเลือกใช้ได้:** ตำแหน่งข้อความวัดจากรายงานเดิม 4 แบบ บนกระดาษเช็คทั้งแผ่น 9.5" × 3.5" — Rcheck1a = กรุงไทย A/C, Rcheck2a = กรุงไทย Non-AC, Rcheck1b = กสิกรไทย A/C, Rcheck2b = กสิกรไทย Non-AC (วันที่แบบ 19/10/2569, ชื่อผู้รับพร้อมเส้นต่อท้าย, \*\*จำนวนเงินตัวอักษร\*\*, ตราประทับ A/C PAYEE ONLY สีแดงเอียง, เส้นขีดฆ่าหรือผู้ถือ, ต้นขั้วซ้ายมือ) · หน้า "ตั้งค่าแบบฟอร์มเช็ค" กด **⭐ สร้างแบบมาตรฐาน** ได้แบบฟอร์มของตัวเองครบ 4 แบบทันที · แต่ละแบบฟอร์มระบุได้ว่าใช้กับ **A/C, Non-AC หรือทั้งคู่** และตั้งแบบเริ่มต้นแยกตามธนาคาร + ชนิด — ตอนพิมพ์ เมื่อสลับ AC/Non-AC ระบบเปลี่ยนไปใช้แบบฟอร์มที่ตรงชนิดให้อัตโนมัติ (ถ้ายังไม่มีแบบฟอร์ม ใช้แบบมาตรฐานของธนาคารนั้น)
- **รายงานเช็ค:** ช่วงวันที่ / เดือนนี้ / ปีงบประมาณ / ปีนี้, ตามบัญชี/ธนาคาร/สถานะ, สรุปรายวัน-เดือน-ปี, สรุปตามบัญชี, รายการเรียงตามเลขที่เช็ค, พิมพ์ A4 และส่งออก Excel (CSV)

### สิทธิ์การใช้งาน
- ผู้ดูแลระบบ (admin) ใช้ได้ทั้ง 2 ระบบเสมอ
- ผู้ดูแลเปิดสิทธิ์ให้ผู้ใช้แต่ละคนได้ที่ **ผู้ใช้งาน / สิทธิ์** (✉️ ระบบพิมพ์ซอง / 🧾 ระบบพิมพ์เช็ค หรือทั้งคู่) และตอน "+ เพิ่มผู้ใช้งาน"
- ได้สิทธิ์ระบบเดียว → เข้าระบบนั้นทันที · ได้ทั้ง 2 ระบบ → หลังล็อกอินแสดงหน้าต่างเลือกระบบแบบเต็มจอ · ปุ่ม **⇄ สลับระบบ** เปิดหน้าต่างเลือกระบบได้ทุกเมื่อ
- สิทธิ์บังคับในฐานข้อมูลด้วย (ผู้ไม่มีสิทธิ์ระบบใด จะอ่าน/เขียนข้อมูลของระบบนั้นไม่ได้)

# ระบบพิมพ์ซองจดหมาย (Envelope Printing System)

เว็บแอปพลิเคชันสำหรับ **ออกเลขหนังสือส่ง** เรียงต่อกันตามเล่มทะเบียน และ **พิมพ์จ่าหน้าซองจดหมาย** ได้ 2 ขนาด

| ซอง | ขนาด | หมายเหตุ |
|---|---|---|
| ซองขาว | 4.25" × 9.25" (107.95 × 234.95 มม.) | พิมพ์แนวนอน |
| ซองน้ำตาล (ใส่กระดาษ A4) | 8.2" × 10" (208.28 × 254 มม.) | เลือกวางแนวนอน/แนวตั้งได้ในหน้าตั้งค่า |

**เทคโนโลยี:** HTML + JavaScript · [SweetAlert2](https://sweetalert2.github.io) · ฐานข้อมูล**เลือกได้ 2 แบบ** (ฟีเจอร์เหมือนกันทุกอย่าง):

| | แบบที่ 1: MySQL | แบบที่ 2: Supabase |
|---|---|---|
| เปิดเว็บจาก | XAMPP (`http://<เครื่องเซิร์ฟเวอร์>/envelope-print-system/`) | Vercel (GitHub → Vercel) |
| ฐานข้อมูล | MySQL/MariaDB ของ XAMPP (PHP 7.4+/8.x) | Supabase (PostgreSQL + Auth + Storage) |
| ตั้งค่าการเชื่อมต่อ | หน้าตั้งค่าก่อนหน้าเข้าสู่ระบบ → `private/config.php` | Vercel Environment Variables (หรือหน้าตั้งค่าก่อนเข้าสู่ระบบ) |
| โครงสร้างตาราง | สร้างให้อัตโนมัติ (`database/`) | รันไฟล์ `supabase/*.sql` ที่ SQL Editor |
| สำรองข้อมูล | โฟลเดอร์ `private/backups` | Supabase Storage (bucket `backups`) + Vercel Cron 00:00 |
| ขั้นตอนติดตั้ง | หัวข้อ "ขั้นตอนติดตั้งบน XAMPP" | หัวข้อ "ขั้นตอนติดตั้งแบบ Supabase + Vercel" |

ระบบรู้เองว่าใช้แบบไหนจากไฟล์ `config.js`: บน XAMPP ไฟล์นี้ว่าง = MySQL · บน Vercel ระบบสร้างไฟล์ให้ตอน build = Supabase

**ฟอนต์:** ใช้ **TH SarabunPSK** เพียงฟอนต์เดียวทั้งระบบ ทั้งหน้าจอ ซอง และรายงาน (ฝังไฟล์ไว้ใน `fonts/` — SIL Open Font License จาก [SarabunConsortium/TH-Sarabun-PSK](https://github.com/SarabunConsortium/TH-Sarabun-PSK)) จึงพิมพ์ออกมาเหมือนกันทุกเครื่องโดยไม่ต้องติดตั้งฟอนต์

## ความสามารถ

### หน้างานเจ้าหน้าที่
- **ออกเลขหนังสือ**: ค้นหาผู้รับ → คลิกเลือกได้หลายรายการ → จัดลำดับ ↑↓ → ใส่เรื่อง/ชั้นความเร็ว/ขนาดซอง → กด "ออกเลข" ระบบออกเลขเรียงกัน เช่น `ศย 304.019/7` ถึง `/10` ทันที
- **ทะเบียน / พิมพ์ซอง**: แสดงเลขที่ออกเรียงตามลำดับ กรองตามวันที่/เล่ม/สถานะ ติ๊กเลือก (หรือ "เลือกเฉพาะที่ยังไม่พิมพ์") → เลือกซองขาวหรือซองน้ำตาล → **ดูตัวอย่าง** / **พิมพ์** (1 ซอง = 1 หน้า) → ยืนยันแล้วสถานะเปลี่ยนเป็น "พิมพ์แล้ว" (นับจำนวนครั้งที่พิมพ์ซ้ำ)
- แก้ไขชื่อ/ที่อยู่บนซองรายฉบับ, ยกเลิกเลข (ต้องระบุเหตุผล เลขไม่ถูกนำกลับมาใช้ซ้ำ)
- **ผู้รับ / หน่วยงาน**: เพิ่ม/แก้ไข พร้อมค้นหา ตำบล-อำเภอ-รหัสไปรษณีย์ แล้วกรอกให้อัตโนมัติ, สร้างรหัสผู้รับอัตโนมัติ (เช่น `CUS69003730`)

### รายงานการพิมพ์ซอง (ทุกคนดูได้)
- เลือก **รายวัน** (ช่วงวันที่ / เดือนนี้ / เดือนที่แล้ว / 7 วัน), **รายเดือน** (เลือกปี พ.ศ. → 12 เดือน), **รายปี** (ช่วงปี พ.ศ.)
- แยก **ซองขาว / ซองน้ำตาล / ทั้งหมด** — การ์ดสรุป, กราฟแท่งซ้อน (ชี้เพื่อดูตัวเลข), ตารางสรุปพร้อมยอดรวม
- **รายการซองที่พิมพ์ เรียงตามเลขที่หนังสือ** (ลำดับ, เลขที่, วันที่ออกเลข, ผู้รับ, เรื่อง, จำนวนครั้งที่พิมพ์ซองขาว/ซองน้ำตาล, พิมพ์ล่าสุด, ผู้พิมพ์)
- **พิมพ์รายงาน** เป็นกระดาษ A4 เป็นรายการเรียงตามเลขที่หนังสือ (ยอดรวมท้ายรายงาน หัวตารางซ้ำทุกหน้า) พร้อมช่องลงชื่อผู้รายงาน และ **ส่งออก Excel (CSV)** เป็นรายการเดียวกัน
- นับทุกครั้งที่พิมพ์ (พิมพ์ซ้ำนับด้วย) จากตาราง `print_logs` ตามเวลาประเทศไทย

### ตั้งค่าตำแหน่งบนซอง (ผู้ใช้ทุกคนตั้งเองได้)
- ตั้งค่า **แยกซองขาว / ซองน้ำตาล** และ **แยกเป็นรายการ** ทีละบรรทัด: ตราสัญลักษณ์, เลขที่หนังสือ, ชื่อหน่วยงาน, ที่อยู่หน่วยงาน, อำเภอ-จังหวัด-รหัสไปรษณีย์ผู้ส่ง, โทรศัพท์, ชั้นความเร็ว, ช่องชำระค่าฝากส่ง, เรื่อง, เรียน+ชื่อผู้รับ, ที่อยู่ผู้รับ, อำเภอ-จังหวัดผู้รับ, รหัสไปรษณีย์ (แบบกล่อง/ตัวเลข)
- แต่ละรายการ: **แสดง/ซ่อน (ลบออกจากซอง)**, ตำแหน่ง X/Y (มม.), ความกว้าง, ขนาดอักษร, ตัวหนา, ตัดบรรทัด (ถ้าไม่ตัด ข้อความยาวจะย่อให้พอดีความกว้างอัตโนมัติ ไม่ทับบรรทัดอื่น)
- **+ เพิ่มข้อความ** ของตัวเองได้หลายรายการ (เช่น "ราชการ", "โปรดส่งด่วน") และลบได้
- ย้ายตำแหน่งโดย **ลากบนตัวอย่างซอง** หรือคลิกเลือกแล้วกด **ลูกศร** (0.5 มม. / Shift = 5 มม.)
- เลื่อนทั้งหมด X/Y ให้ตรงเครื่องพิมพ์, ซองน้ำตาลเลือกแนวนอน/แนวตั้ง, พิมพ์ทดสอบขนาดจริง
- การตั้งค่าเป็น **ของแต่ละผู้ใช้**, **ทุกครั้งที่บันทึกเก็บเป็นเวอร์ชันตามวันที่-เวลาและผู้ตั้งค่า** (ดูประวัติ / ใช้เวอร์ชันเก่า / ลบ) และ **โหลดการตั้งค่าจากผู้ใช้อื่นมาบันทึกเป็นของตัวเอง** ได้ในคลิกเดียว (การตั้งค่าแบบเก่าแปลงเป็นแบบรายการให้อัตโนมัติ)

### การพิมพ์ซองขนาดจริง
- กดพิมพ์ → **หน้าตัวอย่างก่อนพิมพ์ขนาดจริง 100%** (มีไม้บรรทัด มม. และขนาดซองกำกับ, สลับ "พอดีหน้าจอ" ได้) → กด "พิมพ์"
- ระบบสร้าง **เอกสารพิมพ์แยกเฉพาะซอง** ขนาดหน้า = ขนาดซองจริง ขอบ 0 และไม่มีชื่อหน้าเว็บ → **ไม่มีหัว/ท้ายกระดาษ (URL, วันที่) ของเว็บไซต์**
- ติ๊ก "ครั้งต่อไปพิมพ์ทันที ไม่ต้องแสดงตัวอย่าง" ได้ (จำไว้ในเครื่องนั้น)
- **พิมพ์ตรงไปที่เครื่องพิมพ์โดยไม่ผ่านหน้าต่างพิมพ์ / PDF Printer**: เปิดระบบด้วย Chrome/Edge แบบ `--kiosk-printing` (คู่มือในหน้าตัวอย่างก่อนพิมพ์ → "วิธีพิมพ์ตรงไปที่เครื่องพิมพ์ทันที")
  ```
  "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing http://<IP เครื่องเซิร์ฟเวอร์>/envelope-print-system/
  ```
  และตั้งเครื่องพิมพ์ซองเป็นเครื่องหลัก + ขนาดกระดาษ 9.25 × 4.25 นิ้ว / 10 × 8.2 นิ้ว ในไดรเวอร์เครื่องพิมพ์

### หน้าผู้ดูแลระบบ (Admin)
- **ภาพรวมระบบ**: ออกเลขวันนี้ / ทั้งปี / รอพิมพ์ / จำนวนผู้รับ, ผู้ขอสิทธิ์รออนุมัติ
- **เล่มทะเบียน**: กำหนดคำนำหน้าเลข (เช่น `ศย 304.019`), ปี พ.ศ., เลขถัดไป, เริ่มเลข 1 ใหม่อัตโนมัติเมื่อขึ้นปี พ.ศ. ใหม่
- **ผู้ใช้งาน**: เพิ่มผู้ใช้ (**เข้าสู่ระบบได้ทันที**), อนุมัติ/ปิดการใช้งาน, ตั้งรหัสผ่านใหม่, ดูเวลาเข้าใช้ล่าสุด, กำหนดบทบาท admin/เจ้าหน้าที่ และสิทธิ์ระบบซอง/เช็ค
- **ข้อมูลหลัก**: รหัสไปรษณีย์, คำนำหน้าชื่อ, จังหวัด
- **ตั้งค่าหน่วยงานและซอง**: ข้อมูลผู้ส่ง, อัปโหลดตราสัญลักษณ์ (เช่น ตราครุฑ), ข้อความช่อง "ชำระค่าฝากส่งเป็นรายเดือน", ปรับตำแหน่งพิมพ์ (มม.) แยกตามซอง, ตัวอย่างสด + พิมพ์ทดสอบ
- **สำรองข้อมูล**: กด "สำรองข้อมูลตอนนี้" (เลือกดาวน์โหลดลงเครื่องด้วยได้) และ **สำรองอัตโนมัติ 00:00 น. ทุกวัน หากเมื่อวานไม่มีการกดสำรอง** เก็บที่เครื่องเซิร์ฟเวอร์ในโฟลเดอร์ `private/backups` แยก **ปี พ.ศ. → เดือน → วันที่** ดูเป็นต้นไม้โฟลเดอร์ ดาวน์โหลด (.json) หรือลบได้
- **การเชื่อมต่อฐานข้อมูล (MySQL ของ XAMPP)**: เฉพาะผู้ดูแลระบบ — ดู/ทดสอบ/เปลี่ยนการเชื่อมต่อ และติดตั้ง/อัปเดตตาราง (ถ้ายังไม่ได้ตั้งค่า ระบบจะแสดงหน้าตั้งค่าก่อนหน้าเข้าสู่ระบบ)

### โครงสร้างโฟลเดอร์สำรองข้อมูล
```
private/backups/              (โฟลเดอร์บนเครื่องเซิร์ฟเวอร์ XAMPP)
└── 2569/                     ปี พ.ศ.
    └── 10/                   เดือน (ตุลาคม)
        ├── 23/               วันที่
        │   ├── backup_2569-10-23_103015_manual.json.gz   ← กดสำรอง
        │   └── ...
        └── 24/
            └── backup_2569-10-24_000012_auto.json.gz     ← อัตโนมัติ 00:00 น.
```
ไฟล์เป็น JSON (บีบอัด gzip) มีข้อมูลทุกตาราง: settings, titles, provinces, postcodes, customers, books, letters, print_logs, profiles, envelope_layouts, cheque_banks, cheque_accounts, cheques, cheque_forms, cheque_print_logs, backup_logs — ปุ่ม "ดาวน์โหลด" ในหน้าเว็บจะคลายไฟล์ให้เป็น `.json` อัตโนมัติ

**กติกาสำรองอัตโนมัติ:** หลังเวลา 00:00 น. ของทุกวัน (เมื่อมีผู้เปิดระบบครั้งแรกของวัน หรือ Task Scheduler) ระบบตรวจว่า *เมื่อวาน* มีการกด "สำรองข้อมูลตอนนี้" หรือไม่ ถ้า **ไม่มี** จะสำรองให้อัตโนมัติ (เก็บในโฟลเดอร์ของวันที่สำรอง) และจะไม่สำรองอัตโนมัติซ้ำในวันเดียวกัน

### ความปลอดภัยของเลขหนังสือ
- ออกเลขใน transaction ที่ **ล็อกเล่มทะเบียน (SELECT … FOR UPDATE)** ขณะออกเลข → หลายคนกดพร้อมกันเลขก็ไม่ซ้ำ ไม่ข้าม
- Unique constraint `(เล่ม, ปี, เลขที่)` + ป้องกันการตั้งเลขถอยหลังซ้ำ
- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ (PHP): ผู้ใช้ที่ยังไม่อนุมัติมองไม่เห็นข้อมูล, เจ้าหน้าที่แก้เล่มทะเบียน/สิทธิ์ผู้ใช้ไม่ได้

## ขั้นตอนติดตั้งบน XAMPP (ประมาณ 10 นาที)

ระบบใช้ **PHP + MySQL/MariaDB ของ XAMPP** ทั้งหมด ไม่ต้องใช้ Supabase / Vercel / อินเทอร์เน็ต (ยกเว้นโหลด SweetAlert2 ถ้ายังไม่ได้วางไฟล์ไว้ในเครื่อง ดูข้อ 5)

### 1) ติดตั้งและเปิด XAMPP
1. ติดตั้ง XAMPP (PHP 7.4 ขึ้นไป แนะนำ PHP 8.x) จาก https://www.apachefriends.org
2. เปิด **XAMPP Control Panel** → กด **Start** ที่ **Apache** และ **MySQL**

### 2) วางไฟล์โปรแกรม
คัดลอกโฟลเดอร์ `envelope-print-system` ทั้งโฟลเดอร์ไปไว้ที่ `C:\xampp\htdocs\envelope-print-system`

### 3) เปิดระบบ → หน้าตั้งค่าการเชื่อมต่อฐานข้อมูล (ครั้งแรก)
เปิดเบราว์เซอร์ที่เครื่องเซิร์ฟเวอร์ไปที่ **http://localhost/envelope-print-system/**
ระบบจะแสดง **หน้าตั้งค่าการเชื่อมต่อฐานข้อมูล ก่อนหน้าเข้าสู่ระบบ** กรอกค่า (ค่าเริ่มต้นของ XAMPP กรอกไว้ให้แล้ว):

| ช่อง | ค่าเริ่มต้น XAMPP |
|---|---|
| Host | `localhost` |
| Port | `3306` |
| ชื่อผู้ใช้ MySQL | `root` |
| รหัสผ่าน MySQL | *(ว่าง)* |
| ชื่อฐานข้อมูล | `envelope_print` (ตั้งชื่ออื่นได้ ใช้ a-z 0-9 _) |

กด **🔌 ทดสอบการเชื่อมต่อ** → กด **💾 บันทึกและติดตั้ง** ระบบจะ
- สร้างฐานข้อมูล (ถ้ายังไม่มี) และตารางทั้งหมด (`database/schema.sql`)
- นำเข้าข้อมูลเริ่มต้นถ้าติ๊กไว้: ค่าหน่วยงาน คำนำหน้า จังหวัด รหัสไปรษณีย์ 7,425 · ผู้รับ/หน่วยงาน 3,591 · เช็คเดิม 13,146 ฉบับ (แสดงความคืบหน้าทีละไฟล์)
- บันทึกค่าการเชื่อมต่อไว้ที่เซิร์ฟเวอร์ในไฟล์ `private/config.php` → **ทุกเครื่องที่เปิดเว็บใช้ค่าเดียวกัน ไม่ต้องตั้งค่าทีละเครื่อง**

> ถ้าต้องการติดตั้งเองผ่าน phpMyAdmin: สร้างฐานข้อมูล (utf8mb4_unicode_ci) → Import `database/schema.sql` แล้ว `database/seed_*.sql` ตามลำดับชื่อไฟล์ → เปิดเว็บแล้วกรอกการเชื่อมต่อ (ระบบจะพบว่าติดตั้งแล้ว)

### 4) เริ่มใช้งาน
1. หน้าเข้าสู่ระบบ → กด **"ขอสิทธิ์ใช้งาน"** → **ผู้ใช้คนแรกจะเป็นผู้ดูแลระบบ (Admin) อัตโนมัติ** แล้วเข้าสู่ระบบ
2. Admin เพิ่มเจ้าหน้าที่ที่เมนู **ผู้ใช้งาน / สิทธิ์ → + เพิ่มผู้ใช้งาน** (เข้าสู่ระบบได้ทันที) กำหนดสิทธิ์ระบบซอง/ระบบเช็ค และปุ่ม **🔑 ตั้งรหัสผ่านใหม่** เมื่อผู้ใช้ลืมรหัสผ่าน
3. ผู้ใช้เปลี่ยนรหัสผ่านเองได้โดย **คลิกที่ชื่อตัวเอง** มุมซ้ายล่าง
4. เครื่องอื่นในเครือข่ายเปิดใช้งานผ่าน `http://<IP เครื่องเซิร์ฟเวอร์>/envelope-print-system/` (เปิด Windows Firewall ให้ Apache พอร์ต 80)

### 5) SweetAlert2 แบบไม่ต้องใช้อินเทอร์เน็ต (แนะนำ)
ระบบโหลด `assets/vendor/sweetalert2.all.min.js` ก่อน ถ้าไม่มีไฟล์จะโหลดจากอินเทอร์เน็ต (cdn.jsdelivr.net)
ถ้าเครื่องในหน่วยงานไม่มีอินเทอร์เน็ต ให้ดาวน์โหลดไฟล์จาก https://cdn.jsdelivr.net/npm/sweetalert2@11.14.5/dist/sweetalert2.all.min.js มาวางที่ `assets/vendor/` ครั้งเดียว

### การเชื่อมต่อฐานข้อมูล (เฉพาะผู้ดูแลระบบ)
- เมนู **ผู้ดูแลระบบ → การเชื่อมต่อฐานข้อมูล**: ดูค่าที่ใช้อยู่ (ไม่แสดงรหัสผ่าน), สถานะตาราง/จำนวนข้อมูล, **เปลี่ยนการเชื่อมต่อ** (ทดสอบก่อนบันทึก, เว้นรหัสผ่านว่าง = ใช้รหัสเดิม) และ **ติดตั้ง/อัปเดตโครงสร้างตาราง** (ใช้หลังอัปเดตโปรแกรม — ข้อมูลเดิมไม่หาย)
- เปลี่ยนไปฐานข้อมูลอื่น → ทุกคนต้องเข้าสู่ระบบใหม่ (บัญชีผู้ใช้อยู่ในฐานข้อมูล)
- **ถ้าวันหลังเชื่อมต่อไม่ได้** (เช่น ลืมเปิด MySQL) ระบบจะแสดงหน้าตั้งค่าการเชื่อมต่อแทนหน้าเข้าสู่ระบบพร้อมสาเหตุ — เพื่อความปลอดภัย **แก้ไขค่าได้จากเครื่องเซิร์ฟเวอร์ (http://localhost/…) เท่านั้น** เครื่องอื่นจะเห็นข้อความให้ติดต่อผู้ดูแล
- หน้าตั้งค่าแบบไม่ต้องเข้าสู่ระบบ เปิดได้เฉพาะตอนยังไม่เคยตั้งค่า หรือยังไม่มีผู้ใช้ในระบบ หลังจากนั้นต้องเป็นผู้ดูแลระบบเท่านั้น

### สำรองข้อมูลอัตโนมัติ 00:00 น.
ระบบสำรองอัตโนมัติ **เมื่อมีผู้เปิดใช้ระบบครั้งแรกของวัน** (ถ้าเมื่อวานไม่มีการกด "สำรองข้อมูลตอนนี้") ถ้าต้องการให้ทำงาน **ตรงเวลา 00:00 น.** แม้ไม่มีใครเปิดระบบ ให้ตั้ง Windows Task Scheduler (เปิด Command Prompt แบบ Run as administrator):
```
schtasks /Create /TN "EnvelopeBackup" /SC DAILY /ST 00:00 /RU SYSTEM /TR "C:\xampp\php\php.exe C:\xampp\htdocs\envelope-print-system\api\cron_backup.php"
```
(เพิ่ม `--force` ท้ายคำสั่งถ้าต้องการสำรองทุกคืนโดยไม่สนใจการกดสำรองเมื่อวาน) — XAMPP ต้องเปิด MySQL ค้างไว้

### ความปลอดภัย
- `private/` (ค่าการเชื่อมต่อ + ไฟล์สำรอง), `database/` และไฟล์ PHP ภายใน `api/` ปิดไม่ให้เปิดผ่านเว็บด้วย `.htaccess` (XAMPP เปิด AllowOverride ไว้แล้ว)
- รหัสผ่านผู้ใช้เก็บแบบ hash (`password_hash`), เข้าสู่ระบบด้วย PHP session (cookie HttpOnly)
- ทุกคำสั่งอ่าน/เขียนข้อมูลตรวจสิทธิ์ที่เซิร์ฟเวอร์ตามตารางและบทบาท (แทน Row Level Security เดิม) ใช้ prepared statements ทั้งหมด
- แนะนำตั้งรหัสผ่านให้ผู้ใช้ `root` ของ MySQL (หรือสร้างผู้ใช้ MySQL แยกสำหรับระบบนี้) แล้วแก้ในหน้าการเชื่อมต่อ

## ขั้นตอนติดตั้งแบบ Supabase + Vercel

### 1) สร้างโปรเจกต์ Supabase และตาราง
1. สมัคร/เข้า https://supabase.com → **New project** (Region: Singapore)
2. **SQL Editor** → รันไฟล์ในโฟลเดอร์ `supabase/` **ตามลำดับ** (คัดลอกทั้งไฟล์ไปวางแล้วกด Run, รันซ้ำได้ไม่เสียข้อมูล):
   `01_schema.sql` → `02_seed_master.sql` → `03a`, `03b` (รหัสไปรษณีย์) → `04a`, `04b` (ผู้รับ/หน่วยงาน) → `06_cheque_schema.sql` → `07_seed_cheques_01` – `07_seed_cheques_10` (เช็คเดิม แบ่งไฟล์ละไม่เกิน ~440 KB เพราะ SQL Editor รับไฟล์ใหญ่ไม่ได้) · (`05_optional_pg_cron.sql` ไม่บังคับ)
3. **Authentication → Sign In / Providers → Email**: แนะนำปิด **Confirm email** (ผู้ใช้ที่ผู้ดูแลสร้างให้เข้าสู่ระบบได้ทันทีอยู่แล้ว)
4. **Project Settings → API**: จดค่า **Project URL**, **anon / publishable key** และ **service_role / secret key** (ค่าสุดท้ายเป็นความลับ ใช้ใน Vercel เท่านั้น)

### 2) ขึ้น GitHub และ Deploy บน Vercel
1. push โฟลเดอร์โปรเจกต์ทั้งหมดขึ้น GitHub
2. Vercel → **Add New → Project** → เลือก repository → Framework Preset: **Other** (ค่า Build/Output ใช้ตาม `vercel.json` อยู่แล้ว)
3. **Environment Variables** (Settings → Environment Variables) แล้ว **Redeploy**:

| ชื่อ | ค่า |
|---|---|
| `SUPABASE_URL` | Project URL เช่น `https://xxxx.supabase.co` |
| `SUPABASE_ANON_KEY` | anon / publishable key |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role / secret key — ใช้สร้างผู้ใช้, ตั้งรหัสผ่านใหม่, สำรองข้อมูล (**ห้ามใส่ที่อื่น**) |
| `CRON_SECRET` | ข้อความสุ่มยาว ๆ อะไรก็ได้ (Vercel ส่งให้ Cron อัตโนมัติ) |

4. เปิดเว็บ → กด **"ขอสิทธิ์ใช้งาน"** ผู้ใช้คนแรกเป็นผู้ดูแลระบบอัตโนมัติ

- ถ้ายังไม่ได้ตั้ง Environment Variables หรือเชื่อมต่อไม่ได้ ระบบจะแสดง **หน้าตั้งค่าการเชื่อมต่อ Supabase ก่อนหน้าเข้าสู่ระบบ** (กรอก URL + anon key ได้ — มีผลเฉพาะเบราว์เซอร์นั้น)
- ผู้ดูแลระบบดูสถานะได้ที่เมนู **การเชื่อมต่อฐานข้อมูล** (แหล่งที่มาของค่า, ตาราง, ฟังก์ชันสร้างผู้ใช้/สำรองข้อมูล)
- บน Vercel ระบบ build คัดลอกเฉพาะไฟล์หน้าเว็บไปที่ `dist/` — ไฟล์ PHP/MySQL (`api/*.php`, `database/`, `private/`) ไม่ถูกส่งขึ้น (`.vercelignore`)
- ย้ายข้อมูลระหว่าง 2 แบบ: ใช้ไฟล์สำรองข้อมูล (.json) ของระบบเป็นต้นทาง

## คำแนะนำการพิมพ์ซอง
- ฟอนต์ TH SarabunPSK ฝังมากับเว็บแล้ว ไม่ต้องติดตั้งในเครื่อง
- หน้าต่างพิมพ์ของเบราว์เซอร์: เลือก**เครื่องพิมพ์จริง** (ไม่ใช่ Save as PDF / Microsoft Print to PDF ซึ่งจะใช้ขนาด A4 ของมันเอง)
- ถ้าพิมพ์เยื้อง ให้ปรับที่เมนู **ตั้งค่าตำแหน่งบนซอง** (แต่ละคนตั้งตามเครื่องพิมพ์ของตัวเอง หรือโหลดจากเพื่อนที่ใช้เครื่องเดียวกัน)
- ใช้ **Google Chrome** หรือ **Microsoft Edge** (รองรับขนาดหน้ากระดาษจาก CSS ได้แม่นยำ)
- หน้าต่างพิมพ์: Margins = **None**, Scale = **100%** (Default), ปิด **Headers and footers**
- ขนาดกระดาษ: ระบบส่งขนาดซองไปให้อัตโนมัติ หากเครื่องพิมพ์ไม่รู้จัก ให้สร้าง Custom paper size ในไดรเวอร์เครื่องพิมพ์ เช่น `9.25 × 4.25 in` และ `10 × 8.2 in`
- ช่อง "เลื่อนทั้งหมด": ค่าบวก = เลื่อนขวา/ลง ค่าลบ = เลื่อนซ้าย/ขึ้น
