# ระบบพิมพ์ซองจดหมาย (Envelope Printing System)

เว็บแอปพลิเคชันสำหรับ **ออกเลขหนังสือส่ง** เรียงต่อกันตามเล่มทะเบียน และ **พิมพ์จ่าหน้าซองจดหมาย** ได้ 2 ขนาด

| ซอง | ขนาด | หมายเหตุ |
|---|---|---|
| ซองขาว | 4.25" × 9.25" (107.95 × 234.95 มม.) | พิมพ์แนวนอน |
| ซองน้ำตาล (ใส่กระดาษ A4) | 8.2" × 10" (208.28 × 254 มม.) | เลือกวางแนวนอน/แนวตั้งได้ในหน้าตั้งค่า |

**เทคโนโลยี:** HTML + JavaScript (ไม่ต้อง build) · [Supabase](https://supabase.com) (PostgreSQL + Auth + Storage) · [SweetAlert2](https://sweetalert2.github.io) · Deploy บน [Vercel](https://vercel.com) (+ Vercel Cron)

**ฟอนต์:** ใช้ **TH SarabunPSK** เพียงฟอนต์เดียวทั้งระบบ ทั้งหน้าจอ ซอง และรายงาน (ฝังไฟล์ไว้ใน `public/fonts/` — SIL Open Font License จาก [SarabunConsortium/TH-Sarabun-PSK](https://github.com/SarabunConsortium/TH-Sarabun-PSK)) จึงพิมพ์ออกมาเหมือนกันทุกเครื่องโดยไม่ต้องติดตั้งฟอนต์

## ความสามารถ

### หน้างานเจ้าหน้าที่
- **ออกเลขหนังสือ**: ค้นหาผู้รับ → คลิกเลือกได้หลายรายการ → จัดลำดับ ↑↓ → ใส่เรื่อง/ชั้นความเร็ว/ขนาดซอง → กด "ออกเลข" ระบบออกเลขเรียงกัน เช่น `ศย 304.019/7` ถึง `/10` ทันที
- **ทะเบียน / พิมพ์ซอง**: แสดงเลขที่ออกเรียงตามลำดับ กรองตามวันที่/เล่ม/สถานะ ติ๊กเลือก (หรือ "เลือกเฉพาะที่ยังไม่พิมพ์") → เลือกซองขาวหรือซองน้ำตาล → **ดูตัวอย่าง** / **พิมพ์** (1 ซอง = 1 หน้า) → ยืนยันแล้วสถานะเปลี่ยนเป็น "พิมพ์แล้ว" (นับจำนวนครั้งที่พิมพ์ซ้ำ)
- แก้ไขชื่อ/ที่อยู่บนซองรายฉบับ, ยกเลิกเลข (ต้องระบุเหตุผล เลขไม่ถูกนำกลับมาใช้ซ้ำ)
- **ผู้รับ / หน่วยงาน**: เพิ่ม/แก้ไข พร้อมค้นหา ตำบล-อำเภอ-รหัสไปรษณีย์ แล้วกรอกให้อัตโนมัติ, สร้างรหัสผู้รับอัตโนมัติ (เช่น `CUS69003730`)

### รายงานการพิมพ์ซอง (ทุกคนดูได้)
- เลือก **รายวัน** (ช่วงวันที่ / เดือนนี้ / เดือนที่แล้ว / 7 วัน), **รายเดือน** (เลือกปี พ.ศ. → 12 เดือน), **รายปี** (ช่วงปี พ.ศ.)
- แยก **ซองขาว / ซองน้ำตาล / ทั้งหมด** — การ์ดสรุป, กราฟแท่งซ้อน (ชี้เพื่อดูตัวเลข), ตารางสรุปพร้อมยอดรวม
- **รายการซองที่พิมพ์ เรียงตามเลขที่หนังสือ** (ลำดับ, เลขที่, วันที่ออกเลข, ผู้รับ, เรื่อง, จำนวนครั้งที่พิมพ์ซองขาว/ซองน้ำตาล, พิมพ์ล่าสุด, ผู้พิมพ์)
- **พิมพ์รายงาน** เป็นกระดาษ A4 เป็นรายการเรียงตามเลขที่หนังสือ (ยอดรวมท้ายรายงาน หัวตารางซ้ำทุกหน้า) พร้อมช่องลงชื่อผู้รายงาน และ **ส่งออก Excel (CSV)** เป็นรายการเดียวกัน
- นับทุกครั้งที่พิมพ์ (พิมพ์ซ้ำนับด้วย) จากตาราง `print_logs` ตามเวลาประเทศไทย

### ตั้งค่าตำแหน่งบนซอง (ผู้ใช้ทุกคนตั้งเองได้)
- ตั้งค่า **แยกซองขาว / ซองน้ำตาล** และ **แยกเป็นรายการ** ทีละบรรทัด: ตราสัญลักษณ์, เลขที่หนังสือ, ชื่อหน่วยงาน, ที่อยู่หน่วยงาน, อำเภอ-จังหวัด-รหัสไปรษณีย์ผู้ส่ง, โทรศัพท์, ชั้นความเร็ว, ช่องชำระค่าฝากส่ง, เรื่อง, เรียน+ชื่อผู้รับ, ที่อยู่ผู้รับ, อำเภอ-จังหวัดผู้รับ, รหัสไปรษณีย์ (แบบกล่อง/ตัวเลข)
- แต่ละรายการ: **แสดง/ซ่อน (ลบออกจากซอง)**, ตำแหน่ง X/Y (มม.), ความกว้าง, ขนาดอักษร, ตัวหนา, ตัดบรรทัด (ถ้าไม่ตัด ข้อความยาวจะย่อให้พอดีความกว้างอัตโนมัติ ไม่ทับบรรทัดอื่น)
- **+ เพิ่มข้อความ** ของตัวเองได้หลายรายการ (เช่น "ราชการ", "โปรดส่งด่วน") และลบได้
- ย้ายตำแหน่งโดย **ลากบนตัวอย่างซอง** หรือคลิกเลือกแล้วกด **ลูกศร** (0.5 มม. / Shift = 5 มม.)
- เลื่อนทั้งหมด X/Y ให้ตรงเครื่องพิมพ์, ซองน้ำตาลเลือกแนวนอน/แนวตั้ง, พิมพ์ทดสอบขนาดจริง
- การตั้งค่าเป็น **ของแต่ละผู้ใช้**, **ทุกครั้งที่บันทึกเก็บเป็นเวอร์ชันตามวันที่-เวลาและผู้ตั้งค่า** (ดูประวัติ / ใช้เวอร์ชันเก่า / ลบ) และ **โหลดการตั้งค่าจากผู้ใช้อื่นมาบันทึกเป็นของตัวเอง** ได้ในคลิกเดียว (การตั้งค่าแบบเก่าแปลงเป็นแบบรายการให้อัตโนมัติ)

### การพิมพ์ซองขนาดจริง
- กดพิมพ์ → **หน้าตัวอย่างก่อนพิมพ์ขนาดจริง 100%** (มีไม้บรรทัด มม. และขนาดซองกำกับ, สลับ "พอดีหน้าจอ" ได้) → กด "พิมพ์"
- ระบบสร้าง **เอกสารพิมพ์แยกเฉพาะซอง** ขนาดหน้า = ขนาดซองจริง ขอบ 0 และไม่มีชื่อหน้าเว็บ → **ไม่มีหัว/ท้ายกระดาษ (URL, วันที่) ของเว็บไซต์**
- ติ๊ก "ครั้งต่อไปพิมพ์ทันที ไม่ต้องแสดงตัวอย่าง" ได้ (จำไว้ในเครื่องนั้น)
- **พิมพ์ตรงไปที่เครื่องพิมพ์โดยไม่ผ่านหน้าต่างพิมพ์ / PDF Printer**: เปิดระบบด้วย Chrome/Edge แบบ `--kiosk-printing` (คู่มือในหน้าตัวอย่างก่อนพิมพ์ → "วิธีพิมพ์ตรงไปที่เครื่องพิมพ์ทันที")
  ```
  "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://<โดเมนของคุณ>.vercel.app
  ```
  และตั้งเครื่องพิมพ์ซองเป็นเครื่องหลัก + ขนาดกระดาษ 9.25 × 4.25 นิ้ว / 10 × 8.2 นิ้ว ในไดรเวอร์เครื่องพิมพ์

### หน้าผู้ดูแลระบบ (Admin)
- **ภาพรวมระบบ**: ออกเลขวันนี้ / ทั้งปี / รอพิมพ์ / จำนวนผู้รับ, ผู้ขอสิทธิ์รออนุมัติ
- **เล่มทะเบียน**: กำหนดคำนำหน้าเลข (เช่น `ศย 304.019`), ปี พ.ศ., เลขถัดไป, เริ่มเลข 1 ใหม่อัตโนมัติเมื่อขึ้นปี พ.ศ. ใหม่
- **ผู้ใช้งาน**: เพิ่มผู้ใช้ (**เข้าสู่ระบบได้ทันที ไม่ต้องยืนยันอีเมล**), อนุมัติ/ปิดการใช้งาน (อนุมัติแล้วยืนยันอีเมลให้อัตโนมัติ), ปุ่ม "ยืนยันให้", ดูเวลาเข้าใช้ล่าสุด, กำหนดบทบาท admin/เจ้าหน้าที่
- **ข้อมูลหลัก**: รหัสไปรษณีย์, คำนำหน้าชื่อ, จังหวัด
- **ตั้งค่าหน่วยงานและซอง**: ข้อมูลผู้ส่ง, อัปโหลดตราสัญลักษณ์ (เช่น ตราครุฑ), ข้อความช่อง "ชำระค่าฝากส่งเป็นรายเดือน", ปรับตำแหน่งพิมพ์ (มม.) แยกตามซอง, ตัวอย่างสด + พิมพ์ทดสอบ
- **สำรองข้อมูล**: กด "สำรองข้อมูลตอนนี้" (เลือกดาวน์โหลดลงเครื่องด้วยได้) และ **สำรองอัตโนมัติ 00:00 น. ทุกวัน หากเมื่อวานไม่มีการกดสำรอง** เก็บใน Supabase Storage แยกโฟลเดอร์ **ปี พ.ศ. → เดือน → วันที่** ดูเป็นต้นไม้โฟลเดอร์ ดาวน์โหลด (.json) หรือลบได้
- **การเชื่อมต่อ Supabase (Manual)**: กรอก Project URL / anon key เองได้จากหน้าเว็บ (มีลิงก์ที่หน้าเข้าสู่ระบบด้วย) พร้อมปุ่มทดสอบ และตรวจสอบสถานะระบบ (Auth, ตาราง, Storage, ระบบสำรองอัตโนมัติ)

### โครงสร้างโฟลเดอร์สำรองข้อมูล
```
backups/                      (Supabase Storage bucket)
└── 2569/                     ปี พ.ศ.
    └── 10/                   เดือน (ตุลาคม)
        ├── 23/               วันที่
        │   ├── backup_2569-10-23_103015_manual.json.gz   ← กดสำรอง
        │   └── ...
        └── 24/
            └── backup_2569-10-24_000012_auto.json.gz     ← อัตโนมัติ 00:00 น.
```
ไฟล์เป็น JSON (บีบอัด gzip) มีข้อมูลทุกตาราง: settings, titles, provinces, postcodes, customers, books, letters, print_logs, profiles, envelope_layouts, backup_logs — ปุ่ม "ดาวน์โหลด" ในหน้าเว็บจะคลายไฟล์ให้เป็น `.json` อัตโนมัติ

**กติกาสำรองอัตโนมัติ:** ทุกวันเวลา 00:00 น. ระบบตรวจว่า *เมื่อวาน* มีการกด "สำรองข้อมูลตอนนี้" หรือไม่ ถ้า **ไม่มี** จะสำรองให้อัตโนมัติ (เก็บในโฟลเดอร์ของวันที่สำรอง) และจะไม่สำรองอัตโนมัติซ้ำในวันเดียวกัน

### ความปลอดภัยของเลขหนังสือ
- ออกเลขผ่านฟังก์ชันฐานข้อมูล `issue_letters()` ที่ **ล็อกเล่มทะเบียน** ขณะออกเลข → หลายคนกดพร้อมกันเลขก็ไม่ซ้ำ ไม่ข้าม
- Unique constraint `(เล่ม, ปี, เลขที่)` + ป้องกันการตั้งเลขถอยหลังซ้ำ
- Row Level Security: ผู้ใช้ที่ยังไม่อนุมัติมองไม่เห็นข้อมูล, เจ้าหน้าที่แก้เล่มทะเบียน/สิทธิ์ผู้ใช้ไม่ได้

## ข้อมูลจากไฟล์ Access (.xls) ที่นำเข้า

| ไฟล์เดิม | ตารางใหม่ | จำนวน | หมายเหตุ |
|---|---|---|---|
| `tblSetup.xls` | `settings` | 1 | ชื่อหน่วยงาน "ศาลจังหวัดอุดรธานี", คำนำหน้าเลข "ศย 304.019", ที่อยู่, โทร/โทรสาร, `CustomerPrefix = CUS` |
| `tblTitle.xls` | `titles` | 7 | นาย, นาง, นางสาว, ดร., ศาสตราจารย์, เด็กหญิง |
| `tblProvince.xls` | `provinces` | 78 | 77 จังหวัด + "-" (ไม่ระบุ) |
| `PostCode.xls` | `postcodes` | 7,425 | ตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์ + หมายเหตุข้อยกเว้น 99 รายการ |
| `tblCustomer.xls` | `customers` | 3,591 | ผู้รับ/หน่วยงาน รหัสเดิมคงไว้ทั้งหมด (`CUS` + ปี พ.ศ. 2 หลัก + เลขลำดับ 6 หลัก) |

รูปแบบรหัสผู้รับเดิม `CUS51000001` = `CUS` + `51` (พ.ศ. 2551) + `000001` (ลำดับ) ระบบใหม่สร้างรหัสต่อจากเดิมในรูปแบบเดียวกัน
(ฟิลด์ `Contact`, `eMail` ในข้อมูลเดิมว่างทั้งหมด ฟิลด์ `PostOffice` ใน PostCode ว่างทั้งหมด — ยังคงช่องไว้ให้ใช้ภายหลัง)

## แนวทางจากระบบ G2G / สารบรรณอิเล็กทรอนิกส์

ระบบออกแบบตามขั้นตอนทะเบียนหนังสือส่งของระบบสารบรรณอิเล็กทรอนิกส์ภาครัฐ: บันทึกรายละเอียดหนังสือ (ถึง/เรื่อง/ชั้นความเร็ว) → **เลือกเล่มทะเบียนเพื่อออกเลขที่หนังสือ** → ระบบแสดงเลขที่ออก → ดำเนินการส่ง (ที่นี่คือพิมพ์จ่าหน้าซอง) โดยเลขที่หนังสือรูปแบบ `ที่ ศย 304.019/เลขลำดับ` แสดงที่มุมซ้ายบนของซองพร้อมชื่อและที่อยู่หน่วยงานผู้ส่ง

## ขั้นตอนติดตั้ง (ประมาณ 15 นาที)

### 1) สร้างฐานข้อมูล Supabase
1. สมัคร/เข้าสู่ระบบ https://supabase.com → **New project** (Region แนะนำ Singapore)
2. ไปที่ **SQL Editor** → **New query** → เปิดไฟล์ในโฟลเดอร์ `supabase/` วางแล้วกด **Run** ทีละไฟล์ **ตามลำดับ**:
   1. `01_schema.sql` — สร้างตาราง ฟังก์ชัน และสิทธิ์
   2. `02_seed_master.sql` — ข้อมูลหน่วยงาน, คำนำหน้า, จังหวัด, เล่มทะเบียนแรก
   3. `03a_seed_postcodes.sql` และ `03b_seed_postcodes.sql` — รหัสไปรษณีย์
   4. `04a_seed_customers.sql` และ `04b_seed_customers.sql` — ผู้รับ/หน่วยงาน
   5. (ไม่บังคับ) `05_optional_pg_cron.sql` — ดูหัวข้อ "สำรองอัตโนมัติให้ตรง 00:00 น. เป๊ะ"

   > `01_schema.sql` รันซ้ำได้ปลอดภัย (ใช้อัปเกรดฐานข้อมูลเมื่อได้ไฟล์เวอร์ชันใหม่) และจะสร้าง Storage bucket `backups` ให้อัตโนมัติ
3. ไปที่ **Authentication → Sign In / Providers → Email** → **ปิด "Confirm email"** → Save
   (แนะนำ เพื่อให้ admin คนแรกสมัครแล้วเข้าได้ทันที — ผู้ใช้ที่ admin สร้าง/อนุมัติภายหลัง ระบบยืนยันอีเมลให้เองอยู่แล้ว แม้เปิด Confirm email ไว้)
4. ไปที่ **Project Settings → API** จดค่า **Project URL**, **anon public key** และ **service_role key** (ใช้เฉพาะระบบสำรองอัตโนมัติ ห้ามเปิดเผย)

### 3) Deploy บน Vercel
1. https://vercel.com/new → **Import** repository `envelope-print-system`
2. Framework Preset: **Other** (ค่าอื่นอ่านจาก `vercel.json` อัตโนมัติ)
3. **Environment Variables**:

   | ชื่อ | ค่า | ใช้ทำอะไร |
   |---|---|---|
   | `SUPABASE_URL` | Project URL | เชื่อมต่อฐานข้อมูล |
   | `SUPABASE_ANON_KEY` | anon public key | เชื่อมต่อฐานข้อมูล (ฝั่งหน้าเว็บ) |
   | `SUPABASE_SERVICE_ROLE_KEY` | service_role key | **สำรองข้อมูลอัตโนมัติ** และ **admin สร้างผู้ใช้โดยไม่ต้องยืนยันอีเมล** (ใช้เฉพาะฝั่งเซิร์ฟเวอร์) |
   | `CRON_SECRET` | ข้อความสุ่มยาว ๆ เช่น `openssl rand -hex 24` | ป้องกันคนอื่นเรียกระบบสำรองข้อมูล |

   ถ้าไม่ตั้ง `SUPABASE_URL` / `SUPABASE_ANON_KEY` ก็ใช้งานได้ โดยกรอกเองที่ลิงก์ **"⚙️ ตั้งค่าการเชื่อมต่อ Supabase"** หน้าเข้าสู่ระบบ (บันทึกในเบราว์เซอร์แต่ละเครื่อง)
4. กด **Deploy** → ได้ลิงก์เว็บ เช่น `https://envelope-print-system.vercel.app`
5. Vercel Cron ใน `vercel.json` (`0 17 * * *` = 00:00 น. เวลาไทย) จะเรียก `/api/backup` ให้อัตโนมัติ ตรวจได้ที่หน้า **สำรองข้อมูล → ทดสอบการสำรองอัตโนมัติ** และ **การเชื่อมต่อ Supabase → ตรวจสอบระบบ**

#### สำรองอัตโนมัติให้ตรง 00:00 น. เป๊ะ (ไม่บังคับ)
Vercel แผนฟรี (Hobby) อาจเรียก Cron ช้าได้ภายในชั่วโมงนั้น (00:00–00:59 น.) ถ้าต้องการให้ตรงเวลา ให้แก้โดเมนและ `CRON_SECRET` ในไฟล์ `supabase/05_optional_pg_cron.sql` แล้วรันใน SQL Editor (ใช้ pg_cron ของ Supabase) — ระบบกันการสำรองซ้ำในวันเดียวกันไว้แล้ว ใช้ร่วมกับ Vercel Cron ได้

> หรือใช้ Vercel CLI: `npx vercel --prod` แล้วตั้งค่า `vercel env add SUPABASE_URL` / `vercel env add SUPABASE_ANON_KEY`

### 4) เริ่มใช้งาน
1. เปิดเว็บ → กด **"ขอสิทธิ์ใช้งาน"** → **ผู้ใช้คนแรกจะเป็นผู้ดูแลระบบ (Admin) อัตโนมัติ**
2. Admin เพิ่มเจ้าหน้าที่ที่เมนู **ผู้ใช้งาน → + เพิ่มผู้ใช้งาน** (หรือให้เจ้าหน้าที่กดขอสิทธิ์เอง แล้ว Admin ติ๊กอนุมัติ)
3. ตรวจสอบเมนู **ตั้งค่าหน่วยงานและซอง** → อัปโหลดตราครุฑ (ถ้าต้องการ) → กด **พิมพ์ทดสอบ** ทั้ง 2 ซอง แล้วปรับค่าเลื่อน X/Y ให้ตรง

## คำแนะนำการพิมพ์ซอง
- ฟอนต์ TH SarabunPSK ฝังมากับเว็บแล้ว ไม่ต้องติดตั้งในเครื่อง
- หน้าต่างพิมพ์ของเบราว์เซอร์: เลือก**เครื่องพิมพ์จริง** (ไม่ใช่ Save as PDF / Microsoft Print to PDF ซึ่งจะใช้ขนาด A4 ของมันเอง)
- ถ้าพิมพ์เยื้อง ให้ปรับที่เมนู **ตั้งค่าตำแหน่งบนซอง** (แต่ละคนตั้งตามเครื่องพิมพ์ของตัวเอง หรือโหลดจากเพื่อนที่ใช้เครื่องเดียวกัน)
- ใช้ **Google Chrome** หรือ **Microsoft Edge** (รองรับขนาดหน้ากระดาษจาก CSS ได้แม่นยำ)
- หน้าต่างพิมพ์: Margins = **None**, Scale = **100%** (Default), ปิด **Headers and footers**
- ขนาดกระดาษ: ระบบส่งขนาดซองไปให้อัตโนมัติ หากเครื่องพิมพ์ไม่รู้จัก ให้สร้าง Custom paper size ในไดรเวอร์เครื่องพิมพ์ เช่น `9.25 × 4.25 in` และ `10 × 8.2 in`
- ช่อง "เลื่อนทั้งหมด": ค่าบวก = เลื่อนขวา/ลง ค่าลบ = เลื่อนซ้าย/ขึ้น

## ทดสอบบนเครื่อง (ไม่บังคับ)
แก้ `public/config.js` ใส่ `SUPABASE_URL` / `SUPABASE_ANON_KEY` แล้วรัน `npm run dev` เปิด http://localhost:3000
